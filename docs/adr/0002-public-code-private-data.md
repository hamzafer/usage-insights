# Public code, private data

The code is public, but recorded **Snapshots**, **Backfill** results and reports never live in the
repo. They hold plans, spending, project names and work patterns. Data lives in a per-user data
directory outside the repo, and every commit gets a personal-info check.

The dashboard runs locally for now. Hosting it later (e.g. Vercel) stays possible, but only behind
login, so the data stays private.
